# QALens

QALens is an AI-powered QA intelligence platform built for software teams using Jira.

Instead of replacing existing QA workflows, QALens augments them by generating test cases, identifying testing gaps, improving bug reports, and providing actionable release insights.

## Vision

Modern QA teams spend too much time writing repetitive documentation and manually reviewing Jira issues.

QALens automates these tasks while keeping QA engineers in control.

## Core Features

- AI Test Case Generator
- Acceptance Criteria Analysis
- QA Coverage Scoring
- Bug Report Assistant
- Release Readiness Dashboard
- Jira Integration
- QA Analytics
- Team Reporting
